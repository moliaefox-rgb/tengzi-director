# 03 · 镜头日志

> **没有日志，你无法复现一个好镜头。**
> 模型不记得上一版，只有这张表记得。

---

## 表

| 日期 | 镜号 | 版本 | 改了什么（一处） | 结论 | 生成次数 | 花费 | 文件 sha256 前 12 位 | 是否采用 |
|---|---|---|---|---|---|---|---|---|
|  | S01-SH01 | v1 | 初版 |  |  |  |  | 否 |
|  | S01-SH01 | v2 | 加了空间平面图 | 瞬移消失 |  |  |  | 是 |

> **后三列是可复现的底线。** 只写"改了什么"你能回忆起过程，但复现不了结果 ——
> 因为文件会被覆盖，你也记不住调了几次、花了多少。字段说明见 `references/evidence-log.md §2`。
> 嫌麻烦时最简版：次数 + 花费 + 哈希前 12 位，三列就够。

---

## 三条纪律

1. **一次只改一行。** 改两行，你不知道是哪一行起作用。
2. **写"改了什么"，不写"优化了一下"。** 前者能复现，后者是废话。
3. **10–15 规则**：同一镜十到十五次还不出，问题不在措辞。拆镜头、删动作、换角度。

---

## 崩因归类（方便回查）

| 崩法 | 多半是哪一块的问题 |
|---|---|
| 脸不像 / 换人 | 参考素材（角色锁缺失或描述被缩写） |
| 多一个人 / 家具复制 | 场景上下文的人数头、正向约束 |
| 人瞬移 / 左右互换 | 空间平面图、首帧空间锁 |
| 机位跑反 | 180 度轴线 |
| 动作糊 | 动作时间轴（一个 beat 塞了多个动作） |
| 眼神死 | 角色表演（缺微事件、缺分阶段眨眼） |
| 像游戏 / 塑料感 | 风格块（前缀被稀释或缺失） |
| 口型不对 / 多台词 | 台词块（台词写进了动作段） |
| 声音每版不同 | 台词块的 voice 描述被改写 |

---

## 值得记下来的东西

不只记失败。**成立了的那一版，要把"为什么成立"写下来**——
下次遇到同类镜头，直接抄那一版的结构。
