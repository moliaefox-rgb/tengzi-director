# 剧本产出归档

> 规则一句话：**一个剧本一个文件夹，所有产出都进那里，不要散落在技能目录里。**

---

## 目录结构

```
剧本/
├── README.md              ← 你在这里
├── _模板/                 ← 复制用，不要改
│   ├── 00-项目事实表.md
│   ├── 01-场次表.md
│   ├── 02-镜头清单.md
│   └── 03-镜头日志.md
└── <剧本名>/              ← 每接一个剧本，建一个
    ├── 00-项目事实表.md    角色/场景/道具/风格/声音 的常量
    ├── 01-场次表.md        先拆事件，不写提示词
    ├── 02-镜头清单.md      逐镜：镜号/时长/机位/内容/台词
    ├── 03-镜头日志.md      每一版的改动与结论
    └── prompts/           可直接粘贴的成品提示词（一镜一文件）
        └── S01-C01.txt
```

---

## 五条规则

1. **一个剧本一个文件夹**，用剧本名，不加日期、不加版本号。
2. **建文件夹的第一步是复制 `_模板/` 里的四份文件**，不要新建空白文件。
3. **提示词一条一个 `.txt`**，编码 UTF-8，纯文本，**不要 Markdown 围栏**——这样可以直接全选粘贴。
4. **重命名只加后缀，不覆盖**：`S01-C01-v2.txt`。旧版留着，日志里能对上。
5. **日志必须写"改了什么"**，不写"优化了一下"。一个月后你只认得出后者是废话。

---

## 命名规则（收到剧本就建，不用问）

| 情况 | 处理 |
|---|---|
| 剧本名带书名号《我的猫系男友》 | **去掉书名号** → `我的猫系男友` |
| 带副标题、集数、文件后缀 | 只取主标题 |
| 带空格或标点 | 保留中文，去掉 `/ \ : * ? " < > \|` |
| 同名文件夹已存在 | **不新建**，直接进已有的，并告诉用户"已存在，继续用" |
| 剧本改名 | **不重建**，改文件夹名，日志里记一笔 |

**建目录的固定动作**（收到剧本后第一步，在写任何提示词之前）：

```bash
cd "C:/Users/zxc18/.workbuddy/skills/seedance-director/剧本"
mkdir -p "<剧本名>/prompts"
cp _模板/00-项目事实表.md "<剧本名>/"
cp _模板/01-场次表.md     "<剧本名>/"
cp _模板/02-镜头清单.md   "<剧本名>/"
cp _模板/03-镜头日志.md   "<剧本名>/"
```

建完立刻填 `00-项目事实表.md` 的**片名 / register / 画幅 / 单集时长**四个字段，
这四项确定之后才谈场次。

---

## 编号规则

```
S01        第 1 场
S01-C01   第 1 场第 1 条（= 一次生成）
```

**一条 = 一次生成（10–30 秒）**，不是剪辑单位。剪出来的刀数在时间轴里定，不进编号。
条号只在**场内**连续，不跨场。这样重排某一场时，其他场的编号不用动。

---

## 每一镜的固定顺序

```
先出事实 → 再出表 → 再出提示词 → 再进日志
```

跳过事实直接写提示词，等于在流沙上盖房子。

## 归档检查

- [ ] `00-项目事实表` 里的角色/场景/风格都是**逐字常量**，没有"大概""类似"
- [ ] `01-场次表` 每场都能填出"每个 beat 几秒"
- [ ] `02-镜头清单` 的时长加起来等于这一场的预算
- [ ] `prompts/` 里的文件和清单里的条号一一对应
- [ ] `03-镜头日志` 里每一版都能看到"改了什么"
