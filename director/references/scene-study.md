# 读剧本：从「发生了什么」到「谁在要什么」

> **这一层补的是全系统最前面的缺口。**
> 之前只有"拆事件"（发生什么 / 说了什么 / 几拍 / 几镜）——那是**剧情摘要**，不是导演读本。
> 结果：镜头只能按时间切，切成六段十五个动作，实测丢十一个（`postmortem.md 案例 001`）。
>
> **证据等级：`[CRAFT]`** —— 来自两位导演/教师的公开工作法，不是生成实测。
> 但 2026-10-20 那次失败**反向验证了它**：按时间切必崩，按"目标变化"切才对。
>
> 来源：
> - Alexander Mackendrick《On Film-making》（CalArts 影视学院院长，学生含 Terrence Davies、James Mangold）
>   「Step Outlines」章原文摘录：https://www.thestickingplace.com/alexander-mackendrick/step-outlines
> - Judith Weston《Directing Actors》剧本分析清单（公开整理版）：
>   https://mattcameronfilm.blogspot.com/2010/08/use-script-analysis-to-uncover-facts.html
> - Bond University 硕士论文对 Weston 方法的转述（Scene Action → Scene Objective → Unit Action）
> - Scalar 教学页「Dramatic Unit」四要素（intention / obstacle / stakes / beat）

---

## 0 · 一句话

**镜头不是按时间切的，是按"谁的目标变了"切的。**

Mackendrick 的定义（原文）：
> 「一场戏不是"发生在一个地理位置里的事件"，而是 **contains one clearly defined purpose and intention**，
> 是一段**由单一主导戏剧张力占据的空间**，内部可以包含一系列更小的 steps（story beats）」

Weston 的定义（转述）：
> 先定整场的 **Scene Action**（这场在干什么），再给每个角色定 **Scene Objective**（他要什么）；
> 冲突来自**两个 objective 对立**；然后把场拆成 **Unit Actions**，
> **任何一个角色的 objective 一变，就换一个 unit**。

**Unit = 镜头。** 这就是镜头数的来源。

---

## 1 · 三步读本（顺序不能反）

### 第一步：写 Scene Action（整场一句话）

格式：**「A 对 B 做了什么」**，一句话，动词开头。

- ✅ 「露娜逼季秋梧把巧克力吐出来」
- ❌ 「两人因为蛋糕发生争执」（这是概括，不是动作）
- ❌ 「露娜很着急」（这是形容词）

> Weston 的纪律：**别被舞台指示带偏，专注关系**（"Don't be distracted by stage directions - concentrate on relationships"）。
> 剧本里的 △ 是给场记看的，不是给导演看的。

### 第二步：给每个角色写 Scene Objective，然后检查对立

格式：**「他要 —— 」**，一个动词短语，指向另一个人。

```
露娜：要让他把嘴里的东西吐出来
季秋梧：要让她相信"我没事"，别再管我
```

**检查**：两个 objective 是**对立**的吗？
- 对立 → 有戏
- 一致 → **这场戏没有冲突，要么改，要么删**
- 一个角色没有 objective → 他在场上只是道具（Weston：不许任何角色"只是在反应"）

> 一个反直觉但极有用的判断（Weston）：
> **角色的主要交战对象不一定是对面那个人**，可能是一个物件、一段记忆、一个不在场的人。
> 例：她对着他说话，但真正在较劲的是"他脸上的指印"。

### 第三步：划 Unit —— objective 一变就是一刀

**这是最关键的一步，也是我上次漏掉的一步。**

```
Unit 1：露娜逼他吐 → 他不吐，只说"我不是普通的猫"
       （露娜的目标：让他吐 → 落空）
Unit 2：露娜改口问"那你吃巧克力也没事？" → 她的目标从"逼他吐"变成"确认他没事"
Unit 3：她放心了，要起身 → 目标变成"离开"
Unit 4：他搂住 → 他的目标从"让她别管"变成"留住她"
```

**四个 unit = 四个镜头。**

不是"六段时间"，是"四次目标变化"。

## 2 · 每个 Unit 要填的四格

```markdown
### Unit N｜<谁的目标变了，从什么变成什么>

- **动作**（他要对对方做什么）：逼 / 哄 / 推开 / 留住 / 试探
- **障碍**（什么挡着他）：她不松手 / 他装听不懂 / 她的手撑在他胸口
- **筹码**（赌注）：被当成猫耍 vs 被当成流氓
- **情绪事件**（观众要感到的那个变化）：从"她占上风"到"她心软"
- **可见证据**（不靠台词也能读到的那个动作）：她的手松开
```

**最后一行是给模型的。** 前四行是你自己的判断，不写进提示词。

---

## 3 · Activity ≠ Action（Mackendrick 第 10 讲）

这是最容易混的一对，也是"演得假"的根源之一。

| | Activity（活动） | Action（动作） |
|---|---|---|
| 是什么 | 手上在干的事 | 对对方干的事 |
| 例子 | 吃蛋糕、端茶、坐沙发、摸手机 | 掩盖、试探、逼问、讨好 |
| 特征 | 可以一个人完成 | 必须有对象 |
| 作用 | 提供质感与生活 | 推动变化 |

**写法**：Activity 写成可见的物理；Action 写成"对对方做什么"。
**两者都要有**——只有 Activity 是生活流，只有 Action 是话剧。

> 我的第四集提示词里全篇都是 Activity（吃、端茶、扑、捏），
> **没有一个 Action 被明确写出来**（她在"逼"，他在"挡"）。
> 所以模型只能把活动演完，读不出戏。

## 4 · 三个可直接用的工具（Weston）

### ① 把负面判断转成问题

不要写「他这段演得假」。写「**他到底想要什么？**」
判断会关上思路，问题会打开。

### ② 形容词换成动词 / 物件 / 事实

| 形容词 | 换成 |
|---|---|
| 她很生气 | 她在**逼**他 |
| 他很尴尬 | 他在**挡**她的话 |
| 气氛暧昧 | 他的手还压在她腰上，**没松** |

Weston 原话：「**把形容词换成动词、画面、事实、事件和物理生活。**」

### ③ 用"就像……"给潜台词

「就像他怕的不是她，是被人看见。」——这句不写进提示词，写进你自己的场景卡，
用来决定"他的视线该往哪躲"。

## 5 · 从 Unit 到镜头：三条硬规则

| 规则 | 说明 |
|---|---|
| **1 Unit = 1 镜头** | 目标变化 4 次 → 4 个镜头。不是按秒数平分 |
| **Unit 内只做一件事** | 她的目标在整段里不变，所以这段里只有一个动作方向 |
| **切点在第 0 秒** | 新 unit 的第一帧就应该是新目标的状态，不要留过渡 |

**为什么必须这样**（实拍证据）：
案例 001 里六个时间段是按"时间感"切的，每段内目标变了两三次，
模型每一次都得选一个执行 → 结果只完成零到一次。

**按 unit 切，模型每段只有一个方向可走。**

## 7 · 接进现有流程（顺序不能乱）

```
① short-drama-craft（本地已有）  判钩子、爽点、节奏波形、集尾留扣
        ↓  【用它的判断，不用它的产能】
② scene-study（本文件）           Scene Action → Objective → Unit → 镜头数
        ↓
③ acting.md（已有）               每个 unit 内：目标/障碍/战术/身体
        ↓
④ blocks.md → 8 块模板            写完
        ↓
⑤ preflight.md（24 项）           交前检查
```

**为什么第一步用 `short-drama-craft`**：它是竖屏短剧的"钩子/爽点/反派/节奏波形"判断手册，
判"这个开场 5 秒立没立住"比通用编剧理论准。**但它明确说"不做生产流水线"**——
正好，生产这一段交给 ②③④。

> **只调用，不复刻。**
> 调用 = 让它出判断，判断结果写进场景卡；它的 `SKILL.md` 与 `references/` **一个字都不动**。
> 本系统不复制、不搬家、不改写任何编剧技能（`SKILL.md §0.8`）。

## 8 · 这套东西治的是哪一种病

| 症状 | 以前怎么处理 | 现在 |
|---|---|---|
| 镜头只能按时间切 | 按秒平分，一段塞三四个动作 | 按 objective 变化切，一段一个方向 |
| 台词念完戏没动 | 归因为"表演假" | 因为**没写 Action，只写了 Activity** |
| 转折丢了 | 归因为"模型漏了" | 因为**转折处没划 unit**，模型不知道那是转折 |
| 不知道删什么 | 凭感觉砍字 | 用「可删清单」：已被动作传达的信息优先删 |
| 角色像道具 | 加动作 | 他在这段没有 objective，先补 objective |

## 9 · 边界：它不是万能的

- **不适用于纯视觉段落**（空镜、蒙太奇、动作场面）。那些靠节奏和物理，不靠 objective。
- **不适用于广告**。广告的"objective"是品牌诉求，不是角色欲望。
- **一个 unit 也可能需要两个镜头**（正反打、插入）。但**一个镜头绝不能装两个 unit。**
- **它是 `[CRAFT]`，不是实测规律。** 三位导演的工作法高度一致，但没有生成实验数据。
  你的项目里跑三条，能稳定降崩，再考虑升级成 `[FIELD]`。
