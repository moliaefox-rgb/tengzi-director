# 证据台账：让每条规则能指回一次真实生成

> SKILL.md §1.5 规定了四道门槛，§3 规定了五个证据标签。
> 但规定不是台账。**没有台账，三个月后你会忘了某条规则从哪来，然后把它当铁律用。**
>
> 本文件给三个模板：规则入库卡、生成记录、对照实验表。
> 加一节查证方法 —— 记录哪些核查动作有效、哪些会骗你。

---

## 1 · 规则入库卡（每条规则进系统时填一张）

```
规则：一个 beat 只放一个动作
标签：[FIELD]
来源：Higgsfield Studio《Hell Grind》项目（官方开源，95 分钟 AI 长片）
来源等级：A · 一手（作者开源，含项目过程记录）
交叉验证：（第二条独立来源，没有就写"无"）
反例/边界：快速动作（挥手、甩头）可以两拍连写；见 failure-modes §1 动作倒放
入库日期：2026-10-20
```

### 字段说明

| 字段 | 规矩 |
|---|---|
| **规则** | 一句话，可执行，不含形容词 |
| **标签** | 只能是 `[FIELD]` `[CRAFT]` `[OFFICIAL]` `[UNTESTED]` `[EXPIRED]` 之一 |
| **来源** | 具体到文件路径或仓库名 + 文件名。**写"网上看到的"等于没有来源** |
| **来源等级** | A 一手（做过片的项目）/ B 生产实践 / C 规格核对 / D 无法核验 |
| **交叉验证** | 至少两个独立来源。**只有一个来源的 `[FIELD]` 要降级成 `[UNTESTED]`** |
| **反例/边界** | 这条规则什么时候不成立。写不出来说明你还没真懂它 |
| **入库日期** | 因为平台会变。`[OFFICIAL]` 尤其需要 |

### 三条硬规矩

1. **`[UNTESTED]` 不许进模板。** 模板写错，后面每条镜头都错（§1.5）。
2. **标 `[REF-xx]` 的来源，不许在交付物里说成"行业标准"。** 它是一套设计得不错的机制，不是被验证过的规律。
3. **一条规则如果只能追溯到"某人的实战总结"，直接归为 D 级。** "实战总结"和"我试过"是同一档证据。

## 2 · 生成记录（每出一批就落一份）

抄自 `renmu2017/Hell-Grind-AIGC-Skill` 的 `examples/after-the-tide/generation-record.json`（239★ MIT）。这是这个赛道里**最可审计**的格式 —— 它连 sha256 都记。

### 为什么记 sha256

因为你会覆盖文件。`S01-SH03_final.txt` 和 `S01-SH03_final_v2.txt` 到底哪个是当时那版？三个月后你答不上来。哈希能答。

### 模板

```json
{
  "date": "2026-10-20",
  "project": "剧名",
  "shot": "S01-SH03",
  "generator": "Seedance 2.5 / omni_reference",
  "model_version": "2.5",
  "resolution": "1080p",
  "duration_s": 12,
  "seed": "unspecified",
  "image_calls": 0,
  "video_calls": 34,
  "retained": 1,
  "cost": { "unit": "credits", "spent": 1751.18, "note": "从 1753 用到 1.82" },
  "reference_inputs": "角色 A 三视图 1 张、场景 3/4 板 1 张；无道具板",
  "prompt_words": 3200,
  "result": "采用 v7",
  "failure_notes": "v1–v5 人物瞬移（缺 GEO）；v6 修正后动作仍糊（一 beat 三动作）；v7 拆 beat 后成立",
  "files": [
    {
      "path": "S01-SH03_v7.txt",
      "bytes": 18234,
      "sha256": "（算一下）"
    }
  ]
}
```

### 最小版（嫌 JSON 麻烦时）

一行就够，写在 `03-镜头日志.md` 的表尾加三列：

| … | 生成次数 | 花费 | 文件 sha256 前 12 位 |
|---|---|---|---|
| | 34 | 1751 credits | a3f9c2e1b7d4 |

**关键不是记多少，是"能复现"。** 没有哈希和次数，日志只是一篇日记。

## 3 · 对照实验表（要验证一条规则时才填）

抄自 `phileiny/h3-storyboard-skill`（180★ MIT）的 `SOURCES.md`。它的价值在于**把"我觉得"变成"我测了，n=2，另一组没测"**。

### 格式

```markdown
| 条目 | 验证方式 | 日期 |
|---|---|---|
| <规则一句话> | <同 seed、同参考、只改一个变量；两组结果对比；给出可量化指标> | YYYY-MM-DD |
| | ⚠️ n=2、同一场、反打未测 | |
```

### 真实例子（照抄它的结构，看它怎么标未验证部分）

> | **节拍密度是表演成败的主因** | 243 帧三版对照，seed 固定，变因逐一隔离：A 一镜 9 拍无台词 → 37–42 dB（脸没动）；B 三镜各一拍无台词 → 22–23 dB（表情到位）；C 三镜各一拍加台词 → 19 dB |
> | | ⚠️ 只测了单人镜，双人中景未测 |

### 三条纪律

1. **必须写"只改了什么"。** 同一版改两处，结论作废。
2. **必须写 n 和未测范围。** 一颗镜头得出的结论，不许当规律。
3. **反例比正例值钱。** 它有一条 `⛔ 用否定句防运镜会【造成】运镜` —— 这种反例比十条成功经验有用。

### 能拿来量什么的指标（实测过的）

| 指标 | 怎么取 | 说明 |
|---|---|---|
| 表情幅度 | 抽帧算脸部区域像素变化（dB） | 判断"表情有没有动" |
| 剪点位置 | 抽帧算场景切换点 | 判断"是不是被提前切了" |
| 嘴动时长 | 逐帧看嘴部开合 | 判断"台词有没有铺满整镜" |
| 台词字错率 | whisper 听写后与原台词比对 | 判断"有没有被改词" |
| 主体占比 | 量主体包围盒 / 画面 | 判断"是不是人太小" |

**注意**：这些指标来自 H3 语境。换成 Seedance 2.5，绝对值不能照搬，**只能照搬"怎么测"**。

## 4 · 查证方法：哪些动作有效，哪些会骗你

这一节是 2026-10-20 那次核查的复盘。**踩过的坑写下来，下次不重踩。**

### ✅ 有效的四个动作

| 动作 | 为什么有效 | 例子 |
|---|---|---|
| **作者账号溯源** | 包内文件名查不到 ≠ 作者没开源。先找作者，再找文件 | 一开始判"61/80 无上游"，查 `feicaiclub` 账号后发现 4 个开源前身，判断要更正 |
| **特有文件名反查** | 名字够独特时，0 命中是强证据 | `bad-acting-atlas`、`mood-master-injection` 全站 0 命中 → 确认非公开搬运 |
| **读 issue 正文，不读 issue 标题** | 标题只有一句抱怨，正文里有复现步骤和使用场景 | 「太多特写了」正文里写着"我把一个短片小说发给 AI 用它分镜" → 这是真的用过 |
| **找作者自己的免责声明** | 作者往往比买家更清楚边界 | cinema-dna README："不是通用成功率或视频生成性能保证" |

### ❌ 会骗你的四个信号

| 信号 | 为什么骗人 |
|---|---|
| **星数** | 7848★ 的 `Emily2040/seedance-2.0`，README 一个字的成片/客户案例都没有。星数只反映收藏 |
| **"实战验证""行业头部项目验证"** | 无法核验的私有项目名。等于没有来源 |
| **高星 + 极少 issue** | 通常是教程引流，不是生产工具。**真当工具用会不断冒 bug**（`[推断]`，不是规律） |
| **README 效果图** | 图不能证明流程跑通过。要看时间线、扣费、审片记录、失败复现 |

### 一条元规则

**能证明"进过生产"的，只有四样东西：成片 / 真实扣费流水 / 逐镜失败复现 / 生成记录（带哈希）。**
其余的（星数、教程、截图、"我用它做了 X"）都只是"有人碰过"。

## 6 · 复查节奏

| 频率 | 查什么 |
|---|---|
| 每出一个项目 | 生成记录是否齐；有没有新反例要写进 `failure-modes.md` |
| 每月 | `[OFFICIAL]` 条款是否过期（时长、参考数、分辨率上限） |
| 每季 | 有没有 `[UNTESTED]` 可以升级成 `[FIELD]`（够 3 次真实生成且结果一致） |
| 每半年 | 来源仓库还活着吗（半年不更新的降级）；license 有没有变 |

**降级不是删除。** 标 `[EXPIRED]` 留档，因为"这条曾经成立过"本身是信息。
