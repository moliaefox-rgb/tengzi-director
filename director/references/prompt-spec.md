# 提示词写法：官方公式 + 实战写法

> **六要素不是另一套骨架，它是十九块的六块子集。**
> 同一套东西，浅一层用：轻量档写单主体单动作，完整档（`blocks.md`）写叙事镜头。
> **轻量档不能进叙事序列**——它缺的正是让镜头之间接得住的那几块。

---

## 一、官方六要素

`[OFFICIAL — 字节《Seedance 2.5 提示词指南》，二手转述两处一致]`

```
主体 + 动作或事件 + 场景与环境 + 视觉风格 + 运镜或切镜 + 声音
```

后四项可选。落到提示词是四行：

```
{主体} 在 {场景} 中 {动作}。
画面呈现 {光线、色彩、材质、质感}。
镜头采用 {景别、机位、运动、对焦对象}。
声音包括 {对白、音色、环境声、音效、音乐}。
```

官方示例：

> 一名陶艺师在清晨的工作室里完成一只浅蓝色陶杯，将它从转盘上取下并放到木架中央。窗外柔和晨光照入室内，湿润陶土呈现细腻光泽，工作台保持整洁。镜头先以中景记录拉坯动作，再缓慢推近陶杯表面的纹理，最后切到木架正面。保留转盘低沉转动声、陶土摩擦声和轻微室内环境声。

### 官方三条硬规矩

| 规矩 | 意思 |
|---|---|
| **一个节拍只写一个主要动作** | 动作优先概括过程，只给关键动作写细节，**不把一个动作翻来覆去描述** |
| **生成参数不进提示词** | 分辨率、帧率、画幅在生成页面设置 |
| **时间戳是节奏指令，不是精确剪辑点** | 用连续区间 `0–3s / 3–6s / 6–9s`，允许模型有自己的判断 |

### 参考素材必须说明职责

`[OFFICIAL]`

```
图像 1 为精确的产品图；视频 1 仅提供镜头运动；音频 1 仅提供节奏。
```

不写，模型自己决定，而且一定决定错。

## 二、十条实战写法

每条都指得出处。**照抄句式，不要照抄内容。**

### ① 参考素材：一行一个角色 + 一句排除

`[OFFICIAL + A 级]`

```
@Image 1 定义主角的脸与衣着。不要取它的姿势、背景、构图。
@Image 2 定义场景与调色。不要取其中的人。
@Video 1 只定义镜头节奏。不要取外观、服装、光、地点。
```

关键在"不要取…"。不写，模型会抄构图而不是抄脸，或抄脸而不是抄配色。

### ② 常数行：开头一段管整条

`[B — lukasersil/seedance-25]`

```
整条片的常量：米色沙发靠后墙、画左一扇窗的午后低光、暖调、浅景深、无文字、无音乐。
```

开头立一次，结尾再提一次。30 秒里模型会忘。

### ③ 时间窗 + 每窗结束状态

`[B — lukasersil]`

```
0–6 秒：{动作}。结束状态：{画面停在哪}。
6–14 秒：{动作}。结束状态：{…}。
14–24 秒：{动作}。结束状态：{…}。
24–30 秒：{动作}。结束状态：{…}。
```

`结束状态`是性价比最高的一句——没有它，模型会在中段自己编。时间轴要**无缝**。

### ④ 首帧锁

`[A — Hell Grind]`

```
首帧已经在画面里：{谁在哪、朝哪、看哪}。没有空镜，没有接近的过程，没有蓄势。
```

### ⑤ 数量头

`[A — Hell Grind]`

```
严格三人——不得重复：A、B、C。
```

模型天生要加人、要复制道具。

### ⑥ 完成态

`[A — OSideMedia FAILURE-MODES]`

```
盖子严密合上并停在那里
杯子在木面上停稳
她的手完全握住把手
```

**不要写"打开"，写"打开之后停在哪"。** 不写，成片里没有一件事真正落地。

### ⑦ 循环动作写成物理

`[A — Higgsfield Studio, RED FLAG 拆解]`

```
脚跟先落地，严格左右交替，任何时候都有一只脚在地面上。
```

走路是模型最难的东西——它画的是"走路的样子"，不是跑那个约束。

### ⑧ 台词块

`[A — Hell Grind + HOUSE 补充]`

```
{A} 的声音（逐字）："{声音描述}"。
她的台词，只说这一句："{台词}"。
其他人不出声；每个可见角色的嘴保持闭合、下颌放松。
无画外音，无即兴加词。
```

最后一句是关键：**"不出声"只管声音，画面还要给每张嘴一个状态**，否则旁边的脸会自己动嘴。

### ⑨ 结尾技术封口

`[A — Hell Grind]`

```
写实。非 IP。9:16。10 秒。只有音效。无 CGI。电影感。用现在时。短句。
```

### ⑩ 单一动作链 + 单一运镜

`[OFFICIAL（一拍一动作）+ A/B]`

一镜一个主运动。要两个就切成两刀各给一个。
一个生成段里可以有很多镜头，但**每个窗口只有一个主要动作**。

## 三、一个完整示例（对话场，可直接改）

```
镜头模式
单镜连续，12 秒，实时，不切。

场景上下文
严格两人——不得重复：A、B。{场景}，{时间}。{发生什么}。

首帧与空间锁
首帧两人已经在画面里：A 在画右，B 在画左，相距约 1.2 米，身体相对，视线互相锁定。

动作时间轴
0.0–4.0 秒：{A 的动作}。结束状态：{停在什么姿势}。
4.0–8.0 秒：{B 的反应，从他台词中途开始}。结束状态：{…}。
8.0–12.0 秒：{距离变化或决定}。结束状态：{…}。

台词
A 的声音（逐字）："{…}"。
A 的台词，只说这一句："{…}"。
B 不说话；嘴保持闭合，下颌放松，只有眼睛在动。
无画外音，无即兴加词。

镜头
手持，坐在视平线，一次 5 度微调，不推不摇不环绕。

画面
{一条光、一个方向、调色}。

写实。非 IP。16:9。12 秒。只有音效。无 CGI。电影感。用现在时。短句。
```

## 四、判档（唯一需要记的一张表）

| 用轻量档（六要素） | 必须用完整档（十九块） |
|---|---|
| 单主体、单动作 | 两人以上 |
| 不跟别的镜头接的一次性画面 | 要进叙事序列（缺首帧锁与数量头，接不上） |
| 产品特写、快速验证 | 有对白、有走位、有情绪转向 |
| 概念试拍 | 任何需要角色一致的镜头 |

**为什么轻量档接不上**：它不写 B02 参考素材、B03 空间平面图、B05 首帧锁、
B10 物理、B14 表演、B17 几何锚点、B18 正向约束——这些正是跨镜一致性的全部来源。

判档在 `SKILL.md §4`，完整档的逐块写法在 `blocks.md`。
