# 出稿前检查表（24 项 + 5 条一票否决）

> 这份表的存在理由：2026-10-20 那次 30 秒实拍，六段十五个动作，成片只完成四个，
> 丢掉的恰好全是"改变关系"的动作。**不是知识不够，是没人拦我。**
>
> 每一项都能**数出来**。数不出来的项不要放进这份表。
> 交付前必须逐项过，并把结果写成一行 `A1 ✓ A2 ✓ …`。**不许说"检查过了"。**

---

## 一、五条一票否决（命中任一，不许出稿）

| # | 红线 | 怎么查 |
|---|---|---|
| **★1** | 出现小数时间戳（`0.0–2.5s`） | 搜索 `.`；2.5 只认**整数秒**（`[OFFICIAL]`） |
| **★2** | 某一段的动作数 **> 3** | 数动词，不是数句子 |
| **★3** | 跨状态动作（站→躺/跪/坐）挤在一段里完成 | 找"倒""扑倒""坐下""跪"这类词 |
| **★4** | 全篇没有一个"整体神情"，只有毫米级肌肉 | 搜"神情""表情""脸色" |
| **★5** | 同场两人服装的明度接近 | 一深一浅，差 ≥2 档 |

---

## 二、A 组 · 结构（4 项）

| # | 检查 | 合格 |
|---|---|---|
| **A1** | 时间戳是否**整数秒**、首尾相接、无缺口 | `0—4 秒 / 4—9 秒 / 9—14 秒` |
| **A2** | 每段结尾是否有**"结束时……"**，且是可见的画面状态（不是"她很难过"） | 官方模板每段都有 |
| **A3** | **镜头数 = 动作改变数**吗？ | 一场戏有几次"关系/信息位置变化"，就该有几个镜头。多出来的镜头是在演"过程" |
| **A4** | 有没有哪一段承担了两个"改变"？ | 一段只许一个"改变"。两个改变必须切段 |

> A3 是这份表里最重要的一条。**镜头是拿来切"改变"的，不是拿来切"时间"的。**

---

## 三、B 组 · 动作（6 项）

| # | 检查 | 合格 |
|---|---|---|
| **B1** | 每段动作数（动词）≤2；≤3 只能用于"因果成对"的动作（捏→松、推→倒） | 数一遍，写下来 |
| **B2** | 大动作（扑、摔、倒地、跳、跑）是否**单独占段**，前后各留 1 秒起势/落定 | 单独一段 |
| **B3** | 跨状态动作是否在**切点断开** | 上段结束在"推上胸口"，下段起手"已在地毯上" |
| **B4** | 每个**抽象动词**是否拆成三件套（哪块身体 / 往哪 / 停在哪） | 搂、捏、嗅、逼、抓、拽、按 |
| **B5** | **逻辑死锁**：前一个动作是否让后一个动作在物理上不可能 | 例：抓住她手腕 → 她起不来 |
| **B6** | 每段有没有**起势**（第 0 秒的状态是"已经在做"，不是"准备做"） | `他正咬下第二口` ✅ / `他准备吃` ❌ |

### B4 的三件套对照（照抄）

| 抽象 | 写成 |
|---|---|
| 搂住 | 右手从她身后绕过去 → 手掌压在后腰侧面 → 往回带 |
| 捏脸 | 两手掌贴住两边脸颊 → 拇指在前四指在后 → 往中间挤 |
| 嗅 | 鼻尖凑到颈侧 → 蹭两下 → 鼻翼张两次 → **嘴唇闭着** |
| 抓握 | 五指扣住 + **握多紧**（轻轻搭着，不握紧） |
| 逼吐 | 一手掐下巴往下压 + 另一手拍后背两下 |

## 四、C 组 · 表演（5 项）

| # | 检查 | 合格 |
|---|---|---|
| **C1** | 每个主要角色至少一个**整体神情**（震惊/错愕/急切/忍着） | 有 |
| **C2** | 每个神情后面紧跟**一个可见身体反应** | `神情一顿，肩膀提起来` |
| **C3** | 有**"不做什么"**（防过度表演） | `但不挣扎、不躲开` |
| **C4** | 有不自主反应：呼吸、眨眼、重心 | 至少两样，写在恒定层 |
| **C5** | 没有纯心理描述（"在藏什么""不许演委屈""关系读法"） | 全部翻译成身体 |

> C1 + C2 + C3 是官方模板的写法：「露出错愕不解的神情，身体下意识稍稍后仰，**但不挣扎、不躲开**」。
> 只有 C1 没有 C2 会僵；只有 C5 没有 C1 会更僵（这就是我上次犯的错）。

---

## 五、D 组 · 视觉可读性（5 项）

| # | 检查 | 合格 |
|---|---|---|
| **D1** | 两人服装**明度差 ≥2 档**，写进【资产锁定】 | `白色上衣/深灰长裤` vs `米白上衣/深棕长裤` |
| **D2** | 侧逆光是否补了**"脸的受光侧仍有细节可见"** | 有。不补 = 剪影 |
| **D3** | 竖屏：人物脸是否落在**画面上 2/3**，避开底部 18% | 有 |
| **D4** | 每个人的视线是否有**具体落点**（他的下巴/她的手/地面） | 有。写"看画外"= 眼神会漂 |
| **D5** | 关键道具是否**锁了数量和位置**（一块蛋糕、一杯茶） | 有 |

> D1 不是审美，是信息可读性。两个人都穿浅色，9:16 小画面里动作归属就乱了，
> 观众分不清是谁在动——这会直接读成"演得乱"。

---

## 六、E 组 · 参数与合规（4 项）

| # | 检查 | 合格 |
|---|---|---|
| **E1** | 台词是否**单独成行**，用「角色台词（情绪）：内容」 | 是 |
| **E2** | 台词后面是否**跟了动作/表情描述** | 不许跟。会诱发字幕（`[OFFICIAL]`） |
| **E3** | 负向是否全部集中在**【排除内容】**，且只针对**真实发生过的失败** | 是。不许抄通用负词表 |
| **E4** | 有没有**自相矛盾**：正面说了 X，别处又禁 X | 全文搜一遍 |

> E4 是元规则。我犯过两次：一边写"只写正面"，一边写"不出现第三只手"；
> 一边写"手轻轻搭着不握紧"，一边写"五指扣住手腕"。
> **规则打架时，模型会随机挑一个执行。**

## 七、出稿时的记录格式

在提示词文件头部写这一行，作为交付凭证：

```
检查：★1✓ ★2✓ ★3✓ ★4✓ ★5✓ | A1✓ A2✓ A3✓ A4✓ | B1✓ B2✓ B3✓ B4✓ B5✓ B6✓
      | C1✓ C2✓ C3✓ C4✓ C5✓ | D1✓ D2✓ D3✓ D4✓ D5✓ | E1✓ E2✓ E3✓ E4✓
```

**有一项不 ✓，不许交付。** 不许写"基本通过"。

## 八、这张表治的是什么病

| 我实际犯过的错 | 被哪一条拦住 |
|---|---|
| `0.0–2.5s` 小数时间戳 | ★1 / A1 |
| 每 2 秒眨一次眼、每下 0.15 秒 | B1（动作数）+ 官方"不许用时间戳控频率" |
| 六段十五个动作，丢十一个 | ★2 / B1 / A3 |
| 她扑倒他，成片是他自己蹲下 | ★3 / B3 |
| "捏脸"演成"掐下巴" | B4 |
| 抓住她手腕 → 她永远起不来 | B5 |
| 全篇毫米级肌肉，表演僵 | ★4 / C1 |
| "在藏什么""关系读法" | C5 |
| 两人同款白碎花 | ★5 / D1 |
| 脸全黑、脸过曝 | D2 |
| 冰箱门占满画面 | D5（位置）+ GEO 里锁开合角度 |
| 台词后面跟动作，出字幕 | E2 |
| 说"只写正面"又写"不出现第三只手" | E4 |

**这张表不产生新知识，它只负责拦住已知的错误。**
