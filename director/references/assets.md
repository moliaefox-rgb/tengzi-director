# 资产：在生成第一个镜头之前

> 一条资产 = **文字 + 图像**。文字是描述词（descriptor），逐字进每一条提示词；图像是参考。
> 缺一个都不成立。这是那部 95 分钟长片省下最多钱的一条规则。

---

## 1 · 角色三视图：三张图，其中一张没有头

```
左：正脸特写（大，3/4 侧转）
中：正面全身 —— 但把头部去掉
右：背面全身
```

**为什么没有头**：全景镜头里，模型会去小全身图上取脸——那里脸又小又糊。把那个头去掉，
模型只有一个地方能取脸：特写。

**为什么要 3/4 侧转**：模型理解得最好的参考图是**大的 3/4 肖像**（脸略转，不是正对镜头）。

**故意做得很无聊**：
- 中性灰背景、平光、真实皮肤（可见毛孔）、不修图
- **不要把电影感烤进三视图**。烤进去，角色会把那个样子带进每一场戏，并且不再对新光反应。
- 电影感长在场景里、长在视频提示词里，不长在三视图上。

**眼睛要查**：再深的眼睛也要有一点眼神光。没有它，脸是死的，而任何视频模型都没法用一张死脸演戏。

---

## 2 · 像不是选的，是挑的

人脸在 Soul Cinema 里出生（皮肤质感最好），但它是个创意模型：一条提示词给好几个不同的脸。
**挑最可信的那张，不是最漂亮的那张。** "漂亮但假"的脸会在视频阶段暴露——那时已经太晚。

---

## 3 · 点改动：永远不整张二次过模型

衣服、疤、血，都是**点改动**：

1. 在原图上用 Nano Banana Pro / Seedream 做那一处改动
2. 到任何支持蒙版的图形工具里，**手工把改动贴回原图**
3. 只有被改的部分覆盖上去，其余像素原封不动

**背后的法律**：`一张图永远不整张过第二次模型。`
每多过一遍，质感掉一层、颜色漂一点；两遍之后脸会变对称、变塑料、变没生命——而那种死质感，之后会毁掉视频里的表演。

---

## 4 · 压力测试（锁资产之前）

**十次生成，不同姿势、不同光。角色必须在 10/10 里都认得出。**

而且不是单独测：
- 放在**其他资产旁边**一起测
- 放在**真实场景的光**里测

一个单独看很稳的主角，和另一个人同框时常常就崩了。
**测试失败，问题在你的描述，不在模型。改字，再测。**

---

## 5 · 状态是独立资产

湿、受伤、换衣服——是 `@roco`、`@roco_wet`、`@roco_blood`，各有各的描述。

混在一段文字里，模型就会在镜头之间把状态混起来。场景同理：白天、夜晚、下雨是三套资产。
道具也一样——关键道具做了三个版本：特写用的完整版、掌心里一闪用的带血小版、握拳时用的"藏起来"版
（提示词里不许露出晶体，只允许指缝间透蓝光）。

**拆分状态比跟模型打架便宜。**

---

## 6 · 场景板

- **拍 3/4，不要正面。** 正面的"漂亮图"在全景里会变成一张平面壁纸，出了它的边界模型每次都在发明新环境。
  3/4 给了模型可读的纵深，几乎能盖住一整圈的机位。
- **每个场景留一个锚点**：一根柱子、一盏灯、一张沙发，把走位绑在它上面。
  "主角在灯下，面向门"能work；"主角在房间里"是抽奖。
- **一套光逻辑**：一个光源、一个阴影方向，**永远不要两个太阳**——否则每个新角度都要重新发明光。
- **反打怎么做**：两种路子。
  1. 用 GPT Image 2 或 NBP 生成同一房间的另一个角，匹配原图的柔焦。
  2. （制作后期才发现的）让 Seedance 生成一段**空场景**、摄影机缓慢走进去的视频——它会按你的图把其他几面画得很一致。
     截你需要的那个角度，拿去 Seedream 或 NBP 提升材质与光。**一张图换出一整套场景板。**

---

## 7 · 图像模型路由

| 任务 | 模型 | 理由 |
|---|---|---|
| 角色 / 选角 / 人像 / 时装 / 一致性 | **Soul 2.0**（或 Cinema Studio AI Cast 自动出参考图） | 为真实人物生成而生；Soul ID 锁同一张脸 |
| 场景 / 环境 / 定场 / 电影静帧 | **Soul Cinema** | 电影级质感、自然颗粒；支持 21:9；可放 Soul ID 角色 |
| 道具 / 产品感物体 | **NBP / GPT Image 2** | 写实产品语境 + 物体上的精确文字 |
| **改一张已有的图 —— 永远第一选择** | **Nano Banana Pro** | 在原图上工作：最小改动，其余像素级保留；最高 4K |
| 只救劣质 AI 纹理（皮肤/布料/表面） | **Seedream 4.5** | 只做纹理，**不做点改动** |
| 最后手段：一个极小局部的精修；或场景的视角反转 | **GPT Image 2** | 整体很"脏"，局部很强 |
| 要重建一帧 | **不是改图** | 回 Soul 模型重新生成 |

### 改图模板

```
Edit the image: [一句话目标].
CHANGE: [唯一变化，写精确].
PRESERVE EXACTLY:
- [脸、衣服、道具、位置、墙地、机位、所有已有阴影]
- Color grade, palette, contrast, grain, falloff
ONLY CHANGE: [重申那一个变化]. 100% identical otherwise.
```

一次只改一个。用户说"你改多了"——就是你改多了：锁更多，改更少。

## 8 · 场景里的反打与视角

- **场景换角度**：GPT Image 2 处理得不错，默认走它。
- 在 NBP 上做，必须**把新的物件排布逐个说清**：
  "主视角里沙发在右；这个反打里沙发在**左**，原本在摄影机后面的门现在在正前方。"
  不写，NBP 会把几何搞乱。

---

## 9 · 图像提示词六条

1. **自然散文，不要关键词堆叠。** `4k, masterpiece, trending` 什么也不采样。
2. **别臃肿。** 80–150 词的精准胜过 400 词的散乱。
3. **正向 > 负向。** 没有负向参数。干净的皮肤写 `clean dry skin`，不写 `no acne`。
4. **画幅与分辨率是平台参数**，不写进正文。
5. **技术性的光与材质**，不要模糊氛围。`single overhead key, 2:1 ratio, smooth falloff` 胜过 `dramatic cinematic lighting`。
6. **一个风格锚点。** 超过 2–3 个风格词，注意力就稀释成通用图。

**另外**：
- 图里的文字要给**确切文案 + 字体/字重/颜色**，含糊的"加个标题"会糊。
- 纹身写具体图案（`classic swallow`、`old-school dagger`）+ `clean line-work`。
- **真人长相不许写进提示词**，翻成特征（脸、体型、气质、年代）。
  但**摄影师/导演的名字可以**——那是技术血缘，不是长相（Hell Grind 的提示词里就明写 `cinematography of Emmanuel Lubezki and Roger Deakins`）。
- 不要出现品牌与 IP。

## 10 · 声音也是一种资产

**声音不是资产，是一个锁死的描述词。**

- 每个主角在前期就把声音锁死：音区、节奏、口音、说话方式。
- 声音描述**逐字**粘进音频段，每次说话都用它，**永不修改**。
- 像测外观一样测声音的跨镜稳定性；漂了，就把措辞锁得更硬。

```
Voice: deep, gravelly bass-baritone; slow, calculated pacing; London street accent;
menacing calm — he never raises his voice.
```

例子里故意写错一个词也会漂——所以是**逐字**。

---

## 11 · 表演也是一种资产

每个主角一段**行为描述**，在任何拍摄之前写好：他怎么动、手在做什么、紧张时的小动作、
眼睛怎么工作、在压力下具体怎么崩。

这段是唯一真相：每场戏把它**改编**到当下的姿势与动作，核心永不变。
一个在这个场景里物理上做不出来的行为，是**转换**，不是删除——坐下的踱步者把能量挪到晃、点手指、碎动作里。

---

## 12 · 资产自查

1. 三视图是"特写 + 正面无头 + 背面"吗？
2. 背景是中性灰、平光、没修图吗？有没有把电影感烤进去？
3. 十次不同姿势的光，10/10 都认得出吗？和别人同框也认得出吗？
4. 每个状态是独立 tag 吗？
5. 场景是 3/4 吗？有没有锚点？是不是一个光源一个方向？
6. 改图是不是用蒙版贴回原图，而不是整张再过一遍？
7. 每个角色的 voice 描述锁死了吗？一个字都不改吗？

---

## 13 · 没有角色资产时：什么能拍，什么不能拍

**这是最常被跳过的一步，代价也最高。**

没有参考图时，描述词就是唯一身份来源。模型每次对同一段描述的理解都不同——**所以不是"差一点"，是每一版都是另一个人。**

### 先分流，再动手

| 镜头类型 | 没角色资产时 |
|---|---|
| 脸部特写、双人情感镜、任何需要观众认人的镜 | **不能拍正片。** 只能测构图与光 |
| 有台词的镜 | 建议等资产。脸不认识，台词就白说 |
| 全景、背影、手的特写、只出现一次的群演 | 可以拍，但只当测试 |

### 无资产版的写法

把参考素材块改成"描述式"，**并且每条提示词逐字复制同一段，永不缩写**：

```
参考素材
本镜没有角色参考图。
露娜——{完整描述：身高体型 / 脸型五官 / 发型 / 标记 / 当前衣着}，逐字重复，永不缩写。
季秋梧——{同上}。
@loc_luna_living 作场景参考——只取空间与材质……（场景照旧）
```

**代价**：跨镜一致性接近于零。所以这一版只用于三件事——
验证构图、验证光、验证动作可行性。**不用于验证"像不像"。**

### 正确的顺序

```
角色三视图 → 压力测试 10/10 → 锁成 @tag + descriptor → 才开拍叙事镜头
```

顺序颠倒的代价不是重拍一条，是**整场都要重跑**。因为脸不认识，观众从头到尾不知道自己在看谁。
