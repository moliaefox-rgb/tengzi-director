# 构图：这一帧为什么值得被看见

> **分工先说清，不然会和 `blocking.md` 打架：**
> - `blocking.md` 管 **人在空间里怎么走** —— GEO、轴线、走位、画幅语法。回答"人在哪"。
> - 本文件管 **这一帧长什么样、为什么是这个位置** —— 观看立场、视线流向、色彩命题。回答"摄影机为什么在这儿"。
> - 落到 19 块里，本文件主要喂 **B05（首帧）、B07（光学）、B11（光照）、以及资产层的场景板/关键帧**。
>
> **证据等级：全部 `[CRAFT-45]`** —— 来自 `cinema-dna`（1506★）与 `zy-cinematic-realism`（619★）。
> 这两个仓库**没有任何生产验证**（作者自己在 README 里否认"性能保证"），issue 里只有两条个人使用反馈。
> 所以：**这是好用的判断框架，不是被验证过的规律。** 不要拿它当铁律，也不要对外说"行业标准"。

---

## 1 · 起点不是景别，是关系

最常见的错误做法：拿到一句戏，先决定"用远景还是特写"。

那是选模板，不是导演。先回答五个问题（`[CRAFT-45]`）：

1. **谁在看谁？**
2. **谁知道得更多？**
3. **谁正在离开，谁还在等？**
4. **人物被什么空间结构限制住？**
5. **观众站在事件的内部、外部，还是错误的一侧？**

答完这五个，机位自然会出来。答不出来就说明这场戏还没想清 —— 回去拆 beat，不要硬写提示词。

> 一句话：**构图不是"画面里有几个人"，是"这几个人之间的权力关系怎么被空间说出来"。**

## 2 · 视线流量：一张图的注意力路线（这是最该抄的一条）

`[CRAFT-45]` 在给 B05 定机位之前，先写一句话：

> 视线从 **A** 进入，被 **B** 放慢或遮住，落到 **C**，最后被 **D** 带走。

四项都要具体：

| 项 | 写什么 | 反例 |
|---|---|---|
| 入口 | 第一眼落在哪（前景的肩、门口的光、地面的水） | "整体很好看" |
| 阻断 | 什么让视线减速（柱子、人群、失焦的帘） | 无 |
| 落点 | 被迫停在哪个决定性信息上（手、印章、空椅） | "人物脸" |
| 出口 | 从哪离开画面，留下什么余韵（画外的门、反光、边缘动作） | 无 |

**一句话说不出来，就是元素堆叠。** 重写。

### 在视频里怎么用

它直接决定三件事：

1. **B05 首帧**：首帧的视线入口必须已经在画面里，不能靠第一秒的运动补。
2. **B08 运镜动机**：镜头往哪走，跟着视线流量的方向走。**流量是从左进右出的，镜头不要反向横移。**
3. **B09 动作时间轴**：视线落点 = 观众注意力的时间点，动作应该在那里发生。

## 3 · 构图压力库（七个，一次只用一个）

`[CRAFT-45]` 每个镜头**只允许一个主要构图机制**，最多加一个辅助。堆三个以上就是"看起来高级但读不出意思"。

| # | 机制 | 适用 | 具体做法 |
|---|---|---|---|
| **A** | **被观察** | 秘密、监视、迟到、身份错位 | 隔玻璃/门缝/人群；前景观察者只出现肩或模糊轮廓；关键动作在中远景 |
| **B** | **被困住** | 制度、命运、心理封闭、仪式 | 几何边界把人物压在局部；极端俯拍；人物尺度小于空间；**空间秩序完整但人物位置偏一处** |
| **C** | **关系疏离** | 家庭、亲密关系、谈判、诀别 | 两人之间留大面积空桌/走廊/地面；视线不相遇；一人在亮区一人在暗区（**不要戏剧化打光**） |
| **D** | **权力不对等** | 审判、仪式、战争、组织 | 低机位或高位俯视，但**必须有现实摄影机位置**；巨大墙面/台阶/人群控制人物比例 |
| **E** | **心理失衡** | 发现、错觉、恐惧、记忆断裂 | 人物贴边；头顶空间过多；轻微倾斜；焦点落在背景而非人物 |
| **F** | **事后状态** | 事件刚结束、人已离开 | 人物缺席；空椅、湿地、开着的门、遗落的衣物；**不拍"解释性证据墙"** |
| **G** | **感官插入** | 决定、犹豫、危险临界点 | 嘴、手、后颈、鞋、湿发、纸张等局部；隐藏身份与空间全貌；**动作停在完成之前** |

### 一图一机制（判定）

❌ 错误：中轴对称 + 极端俯拍 + 门框 + 前景虚焦 + 镜面反射 + 大量负空间
✅ 正确：以门框外部观察为主，人物在远处偏右；其余元素保持普通

**检查方法**：把你的 B05 拆成机制清单，数一下。超过 2 个 → 删。

## 4 · 前景虚焦：必须能解释"摄影机为什么在这儿"

适用条件：**有观察者、有遮挡物、有与剧情有关的物件边缘。**

✅ 有效前景：观察者肩部 / 门框、柱子、窗帘、车窗、座椅 / 近处人群经过 / 植物、栏杆、玻璃反射 / 剧情相关物件的边缘
❌ 无效前景：随机黑块 / 无意义的模糊花草 / 为了"电影感"硬加的遮挡 / **每个镜头都用同一种虚焦轮廓**

`[CRAFT-45]` 每个镜头最多一个前景层，且必须与关系有关。**空镜不需要前景。**

## 5 · 色彩命题：颜色要改变判断，不是好看

`[CRAFT-45]` 每个场景先定一句"色彩命题"，写清五件事：

```
主色域 / 次色域 / 唯一的强调色 / 颜色来自哪里（服装·墙·天气·实拍灯）/ 跨镜怎么变化
```

### 七个可用的演绎方式（选一个，不要全用）

| # | 方式 | 适合 |
|---|---|---|
| 1 | **大色块叙事**（服装、墙体、旗帜形成主色块） | 仪式、权力、历史转折、群像 |
| 2 | **限定色谱**（只围绕少数相邻色，如奶油黄/烟草棕/橄榄绿） | 现代生活、家庭、低调悬疑 |
| 3 | **互补色冲突**（低纯度互补：旧红与病态绿） | 关系冲突（**不要做到 MV 饱和**） |
| 4 | **光色分离**（日光与室内灯不同色温，人物在交界） | 离开、等待、记忆、身份转变 |
| 5 | **空气综合色**（雾/雨/尘/水反射形成整体色） | 海洋、历史、城市、神话 |
| 6 | **高明度**（暖白、浅灰、淡蓝、褪粉，但保留真实曝光） | 白天、医院、机场、制度空间 |
| 7 | **光学混色**（自然光在水面/皮肤间的细微变化） | 午后、花园、海岸、记忆 |

### 三条硬规则

1. **颜色必须有物理来源。** 不许"统一后期染成一种色"。
2. **强调色面积 5%–15%。** 超了就是广告。
3. **不要默认阴冷低饱和。** 这是 `[CRAFT-45]` 明确点名的 AI 病：蓝灰、雨天、低饱和当"电影感"。

### 跨镜连续的五种方式

稳定色域（只变光密度）/ 内外转场（冷外景→暖室内→去色）/ 强调色移动（从人物转到物件）/ 色彩消退（首镜最全，末镜只剩一点）/ 综合色反转（前暖后冷，**必须由空间变化驱动**）

## 6 · 宽银幕（21:9）的真实用途

`[CRAFT-45]` 21:9 不是"更电影"，是一种**关系语法**：

- 展示人物之间的**横向距离**
- 让环境形成社会或心理压力
- 容纳前景/中景/背景三层关系
- 保留**画外空间**
- 构成道路、走廊、海岸、桌面、城墙、队列的叙事

**禁止：把竖幅构图裁一刀当宽银幕。** 人物在 21:9 里会变小 —— 这是特性不是缺陷，但意味着一件事：**21:9 的情绪靠地理，不靠脸。** 要读脸就切 16:9 或推近。

> 三种画幅的走位规则在 `blocking.md §10`，本文件只管"这一帧的构图意图"。

## 7 · 允许的"不完美"（反 CG 的正面写法）

> **负向清单不在这里重复**——统一在 `blocks.md B19【排除内容】`。
> 这一节只留一件事：**正向写出"真片子该有的瑕疵"**，因为正向远比负向有效。

人物部分被挡 / 背景不清晰 / 空间局部普通 / 服装有使用痕迹 / 面部不完美 /
光线不均匀 / 一部分暗部看不清 / 天空轻微过曝

**禁止：为了"高级"让所有物体都精致、干净、发光。**

判据只有一句：**这张图里有没有一处"不完美"是被允许的？** 一处都没有，就是广告片。

## 8 · 参考图隔离：只抽一个维度

`[CRAFT-45]` 用参考图时，**只允许抽一项**，其余两项必须原创：

| 抽什么 | 必须换掉什么 |
|---|---|
| 构图 | 题材、人物关系、动作、道具、综合色、时代 |
| 配色 | 构图、机位、题材、人物、动作、空间骨架 |
| 题材 | 构图、综合色、人物关系、镜头位置、关键物件 |

**判定：只要两项以上高度接近，就是抄。** 重做。

| 构图判断 | 写进哪一块 | 写法 |
|---|---|---|
| 关系压力（谁压制谁） | B05 + B14 | 屏幕位置 + 身体朝向 + 视线落点 |
| 视线流量 | B05 + B09 | 首帧入口在画面里；落点对应 beat 时间 |

**注意：不要把这些词写进提示词。** 模型不认识"关系压力""视线流量"。
要把判断**翻译成可见事实**：不写"关系疏离"，写"两人之间隔着一张空桌，各自朝向不同的门"。

## 10 · 自查（五点，在写提示词之前做）

1. 这场戏的核心关系，能用一句话说出来吗？（说不出来 → 回剧本）
2. 每个镜头的主要构图机制是**一个**吗？（数一遍）
3. 视线流量能一句话描述吗？（不能 → 元素堆叠）
4. 色彩命题有物理来源吗？强调色超过 15% 没有？
5. 五条反 CG 否决项，命中了吗？

**前四问在写提示词之前做，第五问在写完之后做。** 顺序反了会白写。

## 11 · 边界：这套东西不适用于什么

诚实写清楚，避免过度使用：

- **不适用于动作戏的瞬时节拍。** 打斗靠的是节奏和受力，不是构图机制。
- **不适用于 9:16 竖屏的双人贴身戏。** 竖屏靠"对角叠"和前景，见 `blocking.md §10`。
- **不适用于纯功能镜头**（插入镜、过场、道具特写）。那些只需要"看清"，不需要"有立场"。
- **作者自己不主张它是技术标准。** cinema-dna README 原文：「本轮来自实际分镜修正经验与规则自检，**不是通用成功率或视频生成性能保证**。」
