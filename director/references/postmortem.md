## 案例 001｜《我的猫系男友》第四集 · 蛋糕戏｜2026-10-20

**输入**：提示词 v2（6 段：0—3 / 3—6 / 6—10 / 10—16 / 16—22 / 22—26 / 26—30）
30 秒 · 9:16 · 480p Draft · 两条角色资产 + 一条场景资产

**成片**：`a6654ae6…raw.mp4` · 480×854 · 24fps · 721 帧 · 30.05s
**关键帧**：7.0s / 7.6s / 8.2s / 8.8s / 16.5s / 24.0s / 28.0s

### 逐秒实测

| 时间 | 实际发生 | 应该发生 |
|---|---|---|
| 0—7 秒 | 他站着举着蛋糕，**几乎不动**；她在远景慢慢走。整段只有一次重心变化 | 从冰箱拿出、咬一口 |
| 7.0—8.2 秒 | 她走近，抬手摸他脸 | 冲过去推倒 |
| 8.8 秒 | **他自己蹲下了**（她站着） | 她把他压在地毯上 |
| 10—16 秒 | 她**一只手掐住他下颌/脖子**，六秒几乎不动；他的脸全黑 | 两只手捏脸颊往中间挤，把嘴挤开 |
| 16—22 秒 | 她的脸越凑越近，**手一直没离开他的脸** | 松手、退开、问话 |
| 22—26 秒 | **姿势完全没变**，仍在俯身 | 撑起、收腿、跪坐到旁边 |
| 26—30 秒 | 他**跪着把脸埋进她脖子，嘴张开**；她抬头看画面上方 | 搂腰、鼻尖蹭、鼻翼张、嘴闭着嗅 |
| 音频 | 10—16 秒段落 -40～-45 dB（只有环境音），24 字长台词基本没出 | 她一路逼问 |

### 根因

**① ★2 / B1 动作密度超载（主因）**
「6—10 秒」4 秒内写了 5 个动作：三步冲 + 推胸 + 两人同倒 + 落地 + 跨坐。
模型按运动预算分配，选了成本最低路径：**走过去 + 蹲下**。
六段共 15 个动作，实际完成 4 个，丢 11 个 —— 丢的全是"改变关系"的动作
（扑、倒地、松手、起身、搂腰），留下的全是"维持姿势"的动作。

**② ★3 / B3 跨状态动作没有切点**
"站→躺"在一段里完成。模型无法连续完成重心从垂直变水平，
于是让角色**自己蹲下去**——这是它唯一能平滑实现的低重心状态。

**③ B4 抽象动词退化**
- "捏住两边脸颊往中间挤" → 退化成"扣住下颌"（"挤"需要面部变形，成本太高）
- "搂住" → 退化成"靠近"（只需两点接触）
- "嗅" → 退化成"嘴靠近"（**没写"嘴唇闭着"**，模型默认用嘴）

**④ B5 逻辑死锁**
写了"他五指扣住她的右腕"，于是她的"起身"在物理上不可能发生。
整条链卡死在"他抓着她的手腕"，后面"搂住/嗅"全部失去动机。

**⑤ A3 镜头数 ≠ 改变数**
按时间切了 6 段，但这场戏只有 3 次权力移动。
多出来的段在演"过程"，过程正是模型最容易丢的东西。

**⑥ ★4 / C1 表演只有肌肉，没有神情**
通篇写"嘴角单侧下压 2 毫米""喉结滚动一次"，没有一个"整体神情"。
模型缺少表演方向，只能用最保守的方式处理——**面无表情地执行小动作**。

**⑦ ★5 / D1 服装同色**
两人都是白色碎花家居服。9:16 小画面里，观众分不清谁在动。
动作本身没错，读起来"乱"，一半是这个原因。

**⑧ D2 侧逆光过度**
写"脸的大部分在阴影侧"，模型给了一张近乎剪影的脸。
10—16 秒男主的脸完全读不到表情 —— 表演再好也白费。

**⑨ D5 + GEO 缺锁**
冰箱门开了近 90 度，占满画面左侧，压过餐桌与沙发，空间关系崩。
GEO 里只写了"门开着 30 度"，没有在【资产锁定】里复述，被忽略了。

### 修法（已落地）

1. **拆成 4 条独立生成**，每条 7—9 秒，一镜一个动作改变（见 postmortem 对应提示词版本 v3）。
2. **跨状态切一刀**：上条结束在"推上胸口"，下条起手"已在地毯上"。
3. **抽象动词三件套**写进 preflight B4。
4. **删掉"抓手腕"** → 改成"两只手轻轻搭上她的手腕，只是搭着，不握紧"。
5. **每段开头加"神情 + 身体反应 + 不做什么"**。
6. **服装强制明度差**（白/深灰 vs 米白/深棕）。
7. **光补一句**"脸的受光侧仍有细节可见"。
8. **冰箱门写"开 30 度，门边不遮挡餐桌"**，并进【资产锁定】。

## 案例 002｜同一场 · 首版 23 秒（已作废，留档对照）

**输入**：v1，7 段，整数秒，9:16

**用户反馈**：开头单调、两人无互动、表演假。

**根因**：
- 首帧是**静态摆拍**（两人互不看，只有眼珠转和低头）→ 前 2.5 秒没有任何事件
- B14 写了"在藏什么""关系读法"→ 这是给演员的指令，模型读不懂
- 缺不自主反应（呼吸/眨眼）→ 人像定格

**修法**：首帧改成"动作已经发生一半"（手悬在脸旁 0.15 米、要碰没碰）；
B14 改成可见行为；补恒定层。

**教训**：**"静态建立"在短剧里是负资产。** 前 3 秒不需要交代环境，需要张力。

## 案例 003｜两版共同的错：规则自相矛盾（元教训）

同一条提示词里同时出现：

- 「动作只能写成正面」+「不出现第三只手」
- 「他两只手轻轻搭上她的手腕，只搭着，不握紧」+「五指扣住她的右腕」
- 「杯子往桌上一放」+「杯子推到桌角，滑出 0.1 米」

**规则打架时，模型会随机挑一个执行**，或者两个都做一半。

**修法**：出稿前全文搜一遍冲突词（`preflight.md` E4）。
**一条规则只许在一个地方生效。**
