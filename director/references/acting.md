# 表演：写行为，不写情绪

> 三层合一：表演学（`[CRAFT]`）+ Tigran 的任务法（`[CRAFT]`）+ Hell Grind 的生产写法（`[FIELD]`）。

---

## 0 · 公理

**表演是压力下的行为，不是情绪展示。**
一个人想要什么，什么挡着他，他为此做了什么。情绪是这场搏斗的副产品——**永远不要直接写它**。

| 坏 | 好 |
|---|---|
| 表现情绪（"他很生气"） | 追逐目标（"我要让你把钱还回来"）——愤怒自己会长出来 |
| 等自己的 cue | 每一秒都在听对手、反应 |
| 身体给台词配插图（说"大"就张开手） | 身体有自己的生活，有时和台词相反 |
| 全场一个节奏 | 战术一变，节奏就变 |
| 台词来了才开机，台词完了就关机 | 状态是连续的，有"台词之前"和"台词之后" |
| 脸在"表演"（挑眉、咧嘴） | 脸在**想**——眼神在台词之前就把想法读出来了 |

## 1 · 先走 Tigran 的梯子（顺序不能乱）

**第 0 步：先读完这场戏所有的台词。** 不要从一句台词建任务。任务活在整个交换里——哪里守住了，哪里崩了。

**第 1 步：定这场戏唯一的共同目标。** 一个方向，通常是没被说出口的默契："这次别把话说破"、"让这一小时好过一点"。它属于**双方**。

> 场景目标不是这场戏在剧本里的功能（揭示、主题）。角色不知道、也不表演影片的目的——那些是**穿过**他们发生的。

**第 1a 步：先看结尾。** 最后一句/最后一个 beat 是读整场戏的钥匙。注意那句**双关的收尾**：说着这件事，指的是另一件事。

**第 2 步：事件。** 这一场发生了什么改变？谁输了？

**第 3 步：每角色 goal / obstacle / tactic。**
- goal 必须是动词 + 指向具体的人：`让他承认`、`求一个星期的宽限`、`说服她我不害怕`。**不能是状态**（"生气"、"内疚"没法演）。
- obstacle：外部的（对手要相反的东西、屋里有人看着、两小时期限）或内部的（自尊不让他求人、他自己都不信自己的话）。
- **stakes：如果拿不到，会发生什么？** 答案必须让角色害怕。
- tactic 是具体的做法：逼、哄、羞辱、哀求、挑衅、讨价、威胁、拖。

**第 4 步：投入。** 角色**投入在 tactic 里**，不是"摆出某种表情"。
tactic 失败，活人会换一个。**全场一个 tactic = 死表演。**

**关键**：aliveness = 头脑在任务上**可见地工作**，一秒一秒地。
所以眼睛的移动本身就是"做"：一个在争论中的人会不停检查对方**两只眼睛**，找那一点信任的火花，判断对方是感兴趣还是在飘走，然后据此调整。

> **不要用灯光/眼神光去救死眼。给眼睛一个任务。**

## 1.5 · 表演层：一个方向，不同的燃料

`[EMPIRICAL — Tigran's tig-acting-task，经 OSideMedia 复述]`

五支柱是**每个角色**的。它们不解释一群人为什么在同一个场面里。
只用五支柱，戏会读成"几个各自很好的表演，但不在同一部戏里"。

**整场只有一个方向，所有人朝它使力。** 通常是没说出口的默契——"这次别把话说破""让离开不那么疼"。
它属于屋里所有人，**不是**影片的主题：角色从不表演主题，主题是穿过他们发生的。

**每个人朝同一个方向使力，但燃料不同——这就是动机。**
同一个矢量，不同的油。儿子维持体面是"为了妈"，妈是"图个吉利"（出门前哭不吉利）。
**燃料让每个表演各自不同，而场面仍然统一。** 这一层最常被跳过，一跳过，群戏就塌成一个音符重复。

四层要分清（只有后两层属于每个角色）：

| 层 | 属于谁 | 例子 |
|---|---|---|
| 场面方向 | 全体共享 | 让这次不疼 |
| 动机（燃料） | 各自 | 图吉利 / 为了她 |
| 目标 | 各自 | 让他走得有底气 |
| 战术 | 各自 | 照常收拾、偷看 |

给定情境约束动机：已经接了脏活的人，不能演道德清白。动机和背景冲突，就重新推。

### 从结尾命名事件

先看这场戏**怎么结束**，再定它是什么。最后一句或最后一个 beat 是钥匙。
注意那种"双关的收尾"：说着这件事，指着另一件事。

**检验**：事件必须把**在场每一个人**都装进去——包括不出声的、昏迷的，作为参与者或同一过程的镜像。
**哪个角色站在事件外面，事件就命名错了。**

### 物理动作是通道

表面活动（地形）不变，每个角色通过自己的、可拍的行为去追同一个事件。
一个地形（例行查房）、一个事件（寻找自我原谅）、三条通道：

- 一个通过**回忆**——闭着的眼睑下眼动、一滴泪
- 一个通过**把该做的做对**——指标正确、按时、反复核对一条记录
- 一个通过**照顾**——清单之外的护理，先看人再看图表

**给每个在场角色一条自己的物理通道。** 这是把表演笔记变成模型真能生成的东西的关键。

### 对比配对（双人戏的和谐）

一对人建立在互相倒置的 +/− 上：**每人各带一个加号一个减号，相对对方倒置**，
并指定一条**主轴线**——观众真正读到的那组对立。其余性格只是色彩。

例：主轴线是"对病人的在意"。
- **医生：忠诚(+) / 冷漠(−)。** 真忠诚，但忠于机构与钱——加号服务了错的主人，主轴上他是**减**。
- **医助：妥协(−) / 关心(+)。** 接了这份工作就已妥协，但对病人是真的关心——减号是真的，加号在减号里活着，主轴上他是**加**。

两人仍朝同一个场面方向使力。对比活在它**下面**，从战术里漏出来：
冷漠那位的例行是真的，关心那位的例行是盔甲，而且会裂。

**表面的性格常常是对立面的疤。** "冷漠"是希望没了，不是不在意没了。**导历史，不要导表面。**

## 2 · 五支柱（每场戏的拆解必须五样齐全）

| 支柱 | 要求 |
|---|---|
| **目标** | 本场、此刻、从**某个具体的人**身上要什么。动词。 |
| **障碍与代价** | 什么挡住他；失败要付什么。 |
| **战术** | 现在具体怎么做。**失败就换。** |
| **Beat** | 最小的行动单位。一个 beat 在一个目标/一个战术上结束：目标达成、战术失败、新信息到来、力量关系变化。**每个 beat 变化必须可见**：停顿、姿势变化、语速变化、视线转移。一场戏 2–4 个 beat 变化。 |
| **潜台词** | 想的和说的不一样。**潜台词不是演出来的，是没藏住漏出来的。** 可写的标记：不是问句的问句、重复问同一件事（不信答案）、突然换话题、不合适的玩笑（挡脆弱的盾）、太短的回答（"行。""随便。"——一扇关上的门）。 |

## 3 · 生产写法：一段话怎么落笔

Hell Grind 的 CHARACTER ACTING 是**五行**，不是一段散文：

```
ROCO — 状态：烧尽了还在烧。
想要：在任何人看见他失败之前，再来一次干净的动作。
在藏：手臂正在赢，而且这让他害怕。
身体节奏：沉重、扎地、每次爆发之间缓慢恢复。
这镜里变什么：门开的那一秒他把脸重新武装起来——疲惫折回一个干的半笑后面。
```

再叠三样模型真正吃的东西：

**① 内心独白行（INNER，不出声）**
每一段动作配一行"他在想什么、要什么"，标 `INNER`。这给脸一件事做。

**② 分阶段眨眼**（最便宜的生命迹象）
```
one lazy blink → a quick DOUBLE-BLINK → one HARD reset-blink
```

**③ 微生命规则**
静止镜头里**每一到两秒一个可见微事件**：呼吸抬胸、鼻翼动一下、眉一紧一松。
**静止要写成"绷住的张力"，不是"冻住"**——`nobody moves` 这种词会把画面冻死。

## 4 · 身体：先物理，后心理

每个角色四个参数：

| 参数 | 高 | 低 |
|---|---|---|
| **重心** | 胸口、下巴（自信、攻击、地位） | 肩、塌（疲惫、恐惧、顺从） |
| **节奏** | 快、碎（紧张、兴奋剂） | 慢、省（控制、危险——**最危险的人动得最少**） |
| **开合** | 方肩、掌心打开 | 抱臂、低头、封闭 |
| **呼吸** | 高、快（惊慌） | 低、慢（控制）。呼吸是最诚实的指标；刚跑完的人不可能用平稳的声音说话 |

**Business（手上的活）**：角色很少"聊天"，他在修引擎、数钱、擦杯子，然后在上面说话。
- 杀掉虚假的戏剧腔（手在忙真事）
- 产生节奏（停顿有东西填）
- 产生潜台词（**怎么**数钱比台词说得多）
- **被打断的动作是最强的重音**：他本来在切面包，某个词让他停手——这个词就成了事件。

**距离即戏剧**：亲密区（<0.5m，爱或暴力；不请自来就是侵犯）、个人区（0.5–1.2m，信任）、社交区（1.2–3.5m，公事、戒备）、公共区（3.5m+，疏离、等级）。
**距离变化 = beat 变化**。谁靠近、谁断然拉开、谁僵住——很多戏就是这个故事。

**地位是你做什么，不是你是什么**：高地位=头不动、动作慢、长时间凝视、回答前停顿、占空间、碰别人的东西。低地位=忙乱、频繁摸自己、话碎、陪笑、用眼睛请示。
最有意思的是**地位断裂**：老板露出一秒恐惧；下属突然不笑了。

## 5 · 听：表演活在台词之间

1. **反应在对手台词结束前就开始了。** 人在半句里就懂了——脸和身体已经答了。等到台词完才"开机"是死表演。
2. **思考先于说话。** 回答难题前有一个微停顿——他在**决定**说什么。均匀速度的即时回答 = 背台词。
3. **消化时刻。** 重要的事发生（消息、威胁、侮辱）需要时间咽下去：零点几秒到一段长停顿。**特写就活在这个消化里。**
4. **传染。** 节奏、音量、能量随对手变化：一声吼要么被吼回去，要么被刻意的安静压住——**但要回应，不是盖过去**。

## 6 · 声音

- 节奏写在文字里，精确执行；快 ≠ 糊。
- 允许重叠（台词踩尾巴），但关键词要干净。
- **音量反差：最可怕的话说得最轻。** 喊是弱者的货币；掌控场面的人把音量降下来，所有人凑近听。
- 停顿是事件，不是空洞：里面必须发生一件事（评估、决定、拒绝回答）。
- 真实的话有垃圾：打断、半句、重复、没说完。完美的句子会杀死街头感。

## 7 · 眼睛（每条提示词都必须写）

- **微扫视与凝视目标**：眼睛一直在动——飘、在思考时闪开、扫到一个细节再回来。**永不冻在一个点上。**
- **真实的眨眼频率与质量**：压力下急促连眨；控制中缓慢平静的眼睑；解离时一次眨眼后就失焦。
- **活的 catchlight**：眼睛要读起来是湿的、被照到的、活着的。
- **刻意的静止是选择，不是死**：掠食者式的近不眨眼，要写得稀有、缓慢、有意图，并且视线仍在缓慢移动。
- **眼睛先于头**：眼睛比头早一点点到达目标。想法在台词之前就在眼里。
- **眼动随 beat 变**：眨眼率、凝视稳定度、catchlight 的暖度都会随 beat 改变。

## 7.5 · 面部分辨率：写肌肉，不写形容词

`[EMPIRICAL — AU 是标准人类科学；模型对 AU 码的解释是经验性的：成功率高，不是保证]`

写"笑"，模型在一大片素材里漫射采样；写**产生笑的肌肉**，它就具体了。

- `AU6` 眼角提肌（眼轮匝肌收紧，鱼尾纹出现）
- `AU12` 嘴角提肌
- `AU6 + AU12` = **杜兴笑**（真的、眼睛参与的笑）
- 只有 `AU12` = **礼貌的、挤出来的笑**

这个差别对"笑"这个词是隐形的，对 AU 码是一句话的事。**这就是特写里"假"和"真"的分界。**

常用分解：杜兴笑 = `AU6+AU12`；悲伤 = `AU1+AU4+AU15`。

四条使用规矩：

1. **先规划**：这场戏只需要哪 3–4 个表情，只做这几个
2. **一次生成最多 3–4 个**，堆多了准确率下降
3. 两种写法都试：只写码（`AU12`）／码 + 一句解剖描述（"嘴角上提，眼轮匝肌收紧"）
4. **码不是保证。** 反复不出就退回行为描述（下巴紧了两下、鼻子里呼一口气）

FACS 解决的是"特写里的脸"，不解决"这场戏在干什么"。**别用它替代目标与战术。**

## 8 · 状态，不是过渡

视频模型拍不好"过程"，拍得好"状态"。

| 塌 | 立 |
|---|---|
| 伸手进包、拿出来、举起、投出 | **已经投到一半，手臂伸出** |
| 开始跑、加速、冲过去 | **已经全速，重心前压，外套被风撕开** |

把状态一个接一个串起来，不要叙述连续过程。

## 9 · 群体与空间

- **群体反应像波浪，永不同步**：一个人先笑，第二个半拍后，第三个根本没笑。同步的相同反应一眼假。
- **反应比动作更值钱**：每个事件之后，最有价值的画面是**看见它的人的脸**。
- **威胁时冻结**：全场一直在微动（换重心、手势、前倾），关键时刻**全停**。热闹→静止的对比就是标点。
- **移动 = 动机**：没人无缘无故穿过房间。有力的事件：逼近（升级）、转身背对（轻视或藏脸）、别人坐着时站起来（夺权）、冲突中坐下（悖论式权力）、停在门口（门槛=决定点）、开始收拾行李（用身体下最后通牒）。
- **强者静，弱者躁**。危险不是由危险的人演出来的，是由周围人的紧张演出来的。
- **威胁不要预热**：没有阴沉停顿、没有慢动作转身。真实世界里暴力不打招呼。

## 10 · 场景改编（master profile 只能改写，不能粘贴）

1. **只写在场的人。** 画面里没有的角色，不写表演段。
2. **守住不变的核心**：身份、声音、标志性小动作、眼动、情绪主线——这是跨镜一致的来源。
3. **为这一镜重新表达**：选、强调、改、删。
4. **转换，不要删除**：坐着的焦躁者，把能量挪到微晃、抖手腕、撕纸。**能量恒定，出口换了。**
5. **一段话**，不列点、不加标题。
6. **2.5 注意**：动作句里用**人名 + 一个可见标记**（`Mira — silver streak, rust-red jacket —`），
   不要用 `@tag` 当句子主语——那是"一个人变成两个人"的经典成因。tag 只留在 B02 的映射表里。

## 11 · 禁写清单

| 别写 | 改成 |
|---|---|
| `sad / angry / shocked / nervous` | 肌肉的工作：下巴紧了两下、脸颊绷住、鼻子里轻轻呼气 |
| 挑眉、咧嘴、皱眉（指示性表演） | 给脸一个任务，让它自己想 |
| 演结果（一开场就演结局） | 只写角色**此刻知道**的东西 |
| 等 cue（对手说话时脸空白） | 反应从对手台词中间开始 |
| 单战术 | 标 beat，每个 beat 一个新战术动词 |
| 没有 trigger 的眼泪/暴怒 | 搭梯子：克制 → 崩；情绪必须付出代价 |
| `nobody moves` / `frozen` | `stillness as held tension` |
| 年龄 | 角色身份 + 衣着 + 动作 |

## 12 · 自检

**五级刻度**：0 木偶 / 1 朗诵者 / 2 勤奋 / 3 匠人 / 4 活人 / 5 磁石。

- 4 = 行为连续、战术有对比、潜台词与台词分叉、地位在身体里、反应早于台词、至少一个"意外但真实"的选择。
- 5 = 4 的全部 + **悖论**：同时演两个真相（一边帮一边恨；一边道歉一边防守；一边爱一边已经走了）。单一干净的情绪在特写上会显得合成。

**出片前**：目标是不是动词？障碍和代价在不在？2–4 个 beat 变化可见吗？反应早于台词吗？
每人都有手上的活吗？被打断的动作被用上了吗？每个小动作都有 trigger 吗？面具上有裂缝吗？
眼动写清了吗（扫视/眨眼/眼神光/眼先于头）？声音描述逐字粘了吗？有没有情绪词？能不能打 4 分？
