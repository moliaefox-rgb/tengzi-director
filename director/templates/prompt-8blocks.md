# 8 块填空模板（固定结构）

> **为什么要固定结构**：自由越多，模型（和我）发挥越多，幻觉越多。
> 这份模板只有 8 个空，每个空有字数上限和写法要求。填空，不要创作。
>
> 19 块是**思考框架**（写之前想清楚），8 块是**交付格式**（写出来给模型）。
> 交付时只用这 8 块，别把 19 个标题原样贴进去。

---

## 一、空白模板（直接复制）

```
【生成目标】
生成<一个事件，≤2 句>。<题材>风格，<质感>，<时间>，<地点>，<光从哪来>。

【主体与关系】
全程只有 <N> 人：<A>、<B>，没有第三个人。<A> 始终在 <B 的相对位置>。
保持参考人物的脸型、发型、服装、身高关系。<恒定道具>全程<状态不变>。

【资产锁定】
<A> 严格参考@[图片N]。<B> 严格参考@[图片M]。<场景> 严格参考@[图片K]，
只取空间、材质与光线，不继承构图、机位与调色。
服装明度不同：<A 深色/浅色>；<B 深色/浅色>，任何画面里都能分清。

【事件脚本】
0—<X> 秒：<第 0 秒已经在做什么（起势）>。<动作 1>。<动作 2>。结束时<可见状态>。
<X>—<Y> 秒：<承接上段结束状态>。<一个改变>。结束时<可见状态>。
<Y>—<Z> 秒：<承接>。<一个改变>。结束时<可见状态>。

【摄影与声音】
<每段的机位/景别/高度/运动，一个镜头只有一个运动>。机位始终在<某侧>，不越过<某条线>。

<环境底>。<动作音效>。不生成背景音乐，只保留环境音与动作音效。
没有旁白，画面不显示字幕、文字或标牌。

【保持一致】
保持 <N> 人的身份、数量、外貌、服装、身高关系、空间方位、视线方向连续。
<关键道具>的数量与位置不变。<动作顺序>严格按顺序衔接，不提前不跳步。
手部结构正常，<接触点>准确。

【排除内容】
排除<质感失败项>；排除<身份失败项>；排除<手部失败项>；排除<声音失败项>；排除<技术失败项>。
```

## 二、每块的填空纪律

| 块 | 上限 | 不许出现 |
|---|---|---|
| 【生成目标】 | 2 句 | 抽象词（电影感、高级、氛围） |
| 【主体与关系】 | 3 行 | 情绪、关系读法、心理 |
| 【资产锁定】 | 4 行 | 气质描述、风格形容词 |
| 【事件脚本】 | 每段 **≤2 个动作** | 一段里两个"改变"、抽象动词 |
| 【摄影与声音】 | 5 行 | 复合运镜（推+摇+移） |
| 【保持一致】 | 4 行 | 重复前面已写的动作 |
| 【排除内容】 | 1 段，分号分隔 | 通用负词表、没发生过的失败 |

**全程不写**：年龄、心理活动、关系读法、"不许演 XX"、小数秒。

## 三、四组对错写法（都是真实踩过的）

### ① 动作数

❌ `她三步冲过去，双手推上他的胸口，两人一起倒向地毯，膝盖落在他腰两侧。`
（冲 + 推 + 倒 + 落 = 4 个动作 → 成片：她走过去，他自己蹲下）

✅ `她绕过长桌，三步走到他面前。双手推上他胸口——就停在这一下：他重心向后，脚后跟离地。结束时她双手压在他胸口，两个人都在向前倾。`
（走 + 推 = 2 个，倒地留给下一条）

### ② 抽象动词

❌ `他一把搂住她，像猫一样嗅她身上的气味。`
（成片：他跪着把脸埋进她脖子，嘴张开）

✅ `他的右手从她身后绕过去，手掌压在她后腰侧面，往回一带。她的重心被拉回去。他的脸侧转，鼻尖凑到她颈侧，鼻尖蹭两下，鼻翼张两次，嘴唇闭着。`

### ③ 表演

❌ `他极度羞耻，想藏起来，不许演委屈。`（模型乱演）
❌ `嘴角单侧下压 2 毫米，喉结滚动一次。`（模型面无表情）

✅ `他的下颌绷住，眉心皱起，视线落到地面，但没有把脸转开。`

### ④ 服装

❌ `露娜穿居家卫衣，季秋梧穿浅色碎花家居服。`（成片：两人同款白碎花）

✅ `服装明度不同：露娜白色上衣 + 深灰长裤；季秋梧米白上衣 + 深棕长裤。任何画面里都能分清。`

## 四、填好的例子（第四集·条 3：她捏脸，然后松手）

```
【生成目标】
生成露娜跨坐在季秋梧身上、捏开他的嘴逼他吐出来的连续场景。
真人电影风格，写实质感，日间客厅，自然光从右侧落地窗进来。

【主体与关系】
全程只有露娜、季秋梧两人，没有第三个人。露娜始终在季秋梧上方，跨在他腰两侧。
保持参考人物的脸型、发型、服装、身高关系。地毯上那块蛋糕全程停在原处。

【资产锁定】
露娜严格参考@[图片1]。季秋梧严格参考@[图片2]。客厅严格参考@[图片3]，
只取空间、材质与光线，不继承构图、机位与调色。
服装明度不同：露娜白色上衣 + 深灰长裤；季秋梧米白上衣 + 深棕长裤。

【事件脚本】
0—3 秒：季秋梧的后背已经贴着地毯，露娜跨在他腰两侧，双手撑在他胸口。
她俯下身，两只手掌贴住他两边脸颊，拇指在前、四指在后，往中间挤。他的嘴唇被挤开。
结束时他的嘴张着，她的双手还在他脸上。
3—7 秒：露娜台词（急切，语速快，声音拔高）：{谁让你吃这块蛋糕的？猫不能吃巧克力，快吐出来！}
季秋梧的两只手抬起来，轻轻搭上她的手腕，只是搭着，不握紧。他的眉心皱起，下颌绷住，但没有挣开。
结束时他仍被她捏着脸，双手搭在她腕上。
7—9 秒：季秋梧台词（被挤着脸，声音含混）：{我不是那种普通的猫。}
露娜的手停了一下，然后松开，从他脸上收回来，撑在他胸口。
她的肩膀落下去一点，呼吸变慢。结束时她的手已经不在他脸上。

【摄影与声音】
0—3 秒 29 度近景，机高 0.9 米，轻微手持晃动；3—9 秒机位不动，只做极缓慢推近。
机位始终在窗这一侧，不越过餐桌与窗之间的连线。
9:16 竖屏，两人的脸落在画面上三分之二。光从右侧落地窗进来，他的脸在阴影侧，
但受光侧仍有细节可见。
<窗外车流、冰箱低频嗡鸣、衣料摩擦、手掌贴脸时的轻微摩擦音>。
不生成背景音乐，只保留环境音与动作音效。没有旁白，画面不显示字幕、文字或标牌。

【保持一致】
保持两人身份、数量、外貌、服装、身高关系、空间方位、视线方向连续。
地毯上的蛋糕数量为一块，位置不变。捏脸、说话、松手严格按顺序衔接。
手部结构正常，手指不遮住他的眼睛和鼻孔。

【排除内容】
排除卡通感、塑料皮肤、过度磨皮；排除换脸、五官变形、身高突变；
排除多余手指、手指粘连、手掌穿模、第三只手；排除多看镜头；
排除重复台词、口型错位；排除慢动作、跳帧、字幕、水印。
```
