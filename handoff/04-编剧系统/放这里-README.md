# 04 · 编剧系统（请自行放入）

这个位置留给**你的编剧系统**。

本交付包**不包含**编剧系统的任何文件——因为它是独立资产，不该跟着导演系统一起被打包、被改动。

## 怎么放

1. 把你的编剧系统文件夹（例如 `campus-series-forge/` 或 `screenplay-studio/`）**整个复制**到本目录下。
2. 保持它原来的结构，不要改文件名、不要合并进导演系统。
3. 如果它有 `SKILL.md`，确保还在根目录。

放好之后的结构应该是：

```
04-编剧系统/
└── <你的编剧系统>/
    └── SKILL.md
```

## 为什么不合并

- 两边各自升级，互不影响
- 出问题能立刻定位是谁的环节
- 编剧系统的方法论（钩子、爽点、节奏波形）不该进导演系统
- 导演系统的镜头逻辑也不该反过来约束编剧

**它们之间只通过 `01-场景交接卡.md` 说话。**

## 给使用者的说明

如果你的编剧系统也是给别人用的，建议在它自己的 `SKILL.md` 里加一句：

> 本系统负责「故事 → 剧本」。产出的剧本请填入《场景交接卡》，交给导演系统。
> **本系统不写镜头、不写提示词。**

这样两个系统的边界在各自的文件里都写着，不会有人混着用。
