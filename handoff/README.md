## 三条路，按对方能力选

### A. 只想马上试一下 → 用 `03-网页极简版.md`
打开豆包 / Kimi / ChatGPT 网页版，把分割线内的内容粘成第一条消息，然后贴剧本。
**30 秒能出第一条提示词。** 适合单场戏。

### B. 有自己的智能体 → 用 `02-导演系统-通用版.md`
一个文件，不依赖平台。按下面装法丢进去。

### C. 要做一部剧 → 全套
`00` 读一遍 → `01` 每场一张卡 → `02` 装进 agent → 一场一场做。

## 装法（按平台）

| 平台 | 怎么装 |
|---|---|
| **Claude Code / Codex / WorkBuddy** 等有技能目录的 | 新建文件夹 `seedance-director/`，把 `02-导演系统-通用版.md` 改名成 `SKILL.md` 放进去，整个文件夹丢进 skills 目录，**重启会话** |
| **Cursor / Codex Cloud / 有项目约定的** | 把 `02` 的内容放进项目根目录的 `AGENTS.md` 或 `.cursorrules`，或直接放 `README.md` 里 |
| **豆包 / 元宝 / Kimi / 通义** 有"角色/智能体设定"的 | 新建智能体，把 `02` 整份粘进"人设/指令"框，保存 |
| **DeepSeek / 本地 MCP / 自建 agent** | 把 `02` 作为 system prompt 或知识库文件加载 |
| **什么都不想装** | 用 `03`，粘贴即用 |

> 兼容性说明：`02` 是纯 Markdown，不含脚本、不含路径、不联网。
> 只要对方能吃进一段文本，就能用。**唯一的要求是它得能一次读完整份文件。**

## 第一次怎么开口

装好之后，第一句这样说：

```
我有一场戏要拍成提示词。
画幅 9:16，每条 20 秒，角色参考图我有 3 张。
剧本如下：（粘贴）
```

**必须给的三样**：画幅、时长、有没有参考图。缺一样它就会问你。

如果用交接卡：
```
这是场景交接卡，按导演系统处理。
（粘贴卡）
```

## 它会怎么干活（别催它跳步）

1. 先判断这场戏在干什么（谁要什么、谁挡谁）
2. 划 Unit（目标一变一刀）→ **Unit 数 = 镜头数**
3. 按 8 块写提示词
4. 交之前自己数 12 项，给你一行 `检查：1✓2✓…`
5. **先给第一段，你说行再往下**

**如果它一上来就给你十条提示词，说明它跳步了。** 让它"先出 Unit 表"。

## 三个常见误会

**① "能不能自动调编剧系统？"**
不能，也不该。自动调用会让上下文串味、出错时不知道是谁的环节。
串联靠人递卡——这不是麻烦，这是可维护。

**② "为什么一场戏只有三四个镜头？"**
因为镜头是按"目标变化"切的，不是按时间切的。30 秒切六段十五个动作，
真实生成结果只会完成四个，丢的全是转折。

**③ "写得很细，为什么生成还是崩？"**
先看是不是这三种：动作超过 2 个 / 时间戳带小数 / 两人穿同色衣服。
这三样占了崩盘原因的一大半。

## 一句提醒

这套东西**不保证出片**。它是一套纪律，用来减少已知的失败：

- 它的核心规则来自一个 95 分钟 AI 长片的制作系统和一个平台的官方文档
- 它的"动作预算""目标切镜头"来自真实崩过的片子复盘
- 它的失败清单里，每一条都真的崩过一次

**把它当刹车用，不要当引擎用。**
