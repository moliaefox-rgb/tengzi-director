# 00 · 串联说明

> 给谁看：拿到这两个系统、要把一部剧从「故事」做到「可生成的提示词」的人。
> 先说结论：**两个系统各自独立，中间只靠一张卡连接。谁都不许自动调对方。**

---

## 1 · 分工

| 系统 | 负责 | 产出 | 不负责 |
|---|---|---|---|
| **编剧系统**（校园剧） | 故事 → 剧本 | 剧本 / 场次表 / 人物小传 / 集尾钩子 | 不写镜头，不写提示词 |
| **导演系统** | 剧本 → 提示词 | 场景卡 → Unit 表 → 8 块提示词 → 自检 | 不改剧情，不写台词，不做钩子判断 |

**中间那条线是一张纸：《场景交接卡》。**
编剧填完上半张，导演从上半张开工；导演永远不回头问编剧"这场是什么意思"。

```
故事 ──[编剧系统]── 剧本 + 交接卡 ──[导演系统]── Unit 表 + 提示词
                          ↑
                    唯一的接口，只有六格
```

---

## 2 · 三种入口（按你手上有什么选）

### 入口 A：只有一句话想法
```
编剧系统：写这一集 → 交出剧本 + 交接卡
导演系统：读交接卡 → 出提示词
```
这是标准路径。

### 入口 B：已经有剧本（最常见）
```
跳过编剧系统。
把剧本这一场贴进「交接卡」的【剧本原文】格，
自己填三个判断格：整集功能 / 信息差 / 不能动的东西。
交给导演系统。
```
**注意：贴原文，不要贴摘要。** 摘要里没有动作细节，导演系统提不出 Unit。

### 入口 C：只有分镜表，没有剧本
```
导演系统能直接吃分镜表，但会缺"这场为什么存在"。
先回答一个问题：这场在整集里干什么？
答不出来，回编剧系统补，不要硬写。
```

---

## 3 · 交接卡怎么用（最省事的做法）

交接卡有两种形态，**用哪种都行**：

| 形态 | 什么时候用 | 要填几格 |
|---|---|---|
| **形态一：贴剧本** | 有剧本原文 | **只填 3 格**（整集功能 / 信息差 / 不能动的东西）+ 贴原文 |
| **形态二：填表** | 没剧本，只有想法或大纲 | **填 6 格** |

模板在 `01-场景交接卡.md`，复制一份填就行，不用装任何软件。

---

## 4 · 三个检查点（串联只有这三处会出错）

### 检查点 1：交出交接卡之前
- [ ] 剧本原文是**逐字**的，不是摘要
- [ ] 「整集功能」一句话说得出来（推进什么 / 埋什么 / 反转什么）
- [ ] 「不能动的东西」写清了：哪句台词必须原样、哪个动作是集尾钩子

**这一格空着，后面全错。** 导演系统会自己猜"这场为什么存在"，猜错了整场戏的镜头都是错的。

### 检查点 2：导演系统出 Unit 表之后
- [ ] Unit 数 = 你预期的镜头数量级吗？
  - 一场 30 秒的对话戏，通常 **3–5 个 Unit**。出来 8 个，说明切太碎；出来 1 个，说明没找到转折。
- [ ] 每个 Unit 有没有一个"可见证据"（不靠台词也能读到的动作）？
- [ ] 最后一个 Unit 是不是落在集尾钩子上？

**这一步不过，不要往下写提示词。** 提示词写得再好，Unit 错了就是白写。

### 检查点 3：提示词交付之前
- [ ] 导演系统给了 `检查：★1✓…E4✓` 这行凭证
- [ ] 有没有整数秒时间戳
- [ ] 每段有没有"结束时……"

---

## 5 · 出错时怎么定位（谁的环节）

| 症状 | 大概率是谁的问题 | 怎么修 |
|---|---|---|
| 剧本看不懂，不知道这场要干嘛 | **编剧** | 回编剧系统补"整集功能"，不是让导演硬猜 |
| 台词念完戏没动 | **编剧** | 这场没有冲突（两个目标一致），缺戏 |
| Unit 表和你想的不一样 | **导演** | 目标判断错了；把「不能动的东西」写得更具体 |
| 镜头切开后每段都很短 | **导演** | 切太碎，合并相邻 Unit |
| 提示词生出来动作乱 | **导演** | 动作超载，见 `02-导演系统-通用版.md` 的动作预算 |
| 人物不像 | **都不是** | 资产没锁。回去做三视图 |

**定位原则：先看交接卡，再看 Unit 表，最后才看提示词。** 90% 的问题在前两步。

---

## 6 · 三条禁止（这三条是分工的底线）

1. **导演系统不许改剧情、改台词、加角色。**
   发现剧本有问题，写进「上游观察」，交回编剧，不要自己补。

2. **编剧系统不许写镜头、写提示词。**
   写了也不用——导演系统会重排，白做。

3. **两边都不许自动调对方。**
   串联靠人递卡。自动调用的后果是：上下文串味、出错时不知道是谁，
   而且升级任一方都可能悄悄改变另一方的行为。

---

## 7 · 一句话记住

> **编剧负责"这一场为什么存在"，导演负责"这一场怎么被看见"。**
> 中间那张卡，就是这两句话的交界。
